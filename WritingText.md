blobUrl is assigned only from URL.createObjectURL(blob), where blob is the binary PDF (application/pdf) returned by @react-pdf/renderer pdf(...).toBlob() in the client. The URL is always the opaque same-origin form blob:https://<app-origin>/<UUID>. No review data, database field or user input is concatenated into it, so a javascript:, data: or external URL cannot occur. The anchor is created with document.createElement and used only to trigger the PDF download.
